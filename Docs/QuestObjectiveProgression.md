# 퀘스트 목표의 선행 달성 기준

플레이어가 의뢰를 듣기 전에 달성할 수 있는 조건은 미리 달성할 수 있다. 의뢰 수락 여부와 세계에서 이미 일어난 일을 별도로 기록한다.

- 물건 획득, 장치 작동 같은 완료 사실은 안정적인 목표 ID로 저장한다. 대화 단계만으로 소지·완료 여부를 판단하지 않는다.
- 새 의뢰나 목표 단계에 들어갈 때 먼저 기존 완료 사실을 확인한다. 충족했다면 해당 수행 단계를 건너뛰고 완료 보고나 다음 단계로 연결한다.
- 대사는 미리 준비한 경우, 의뢰 후 완수한 경우, 아직 미완료인 경우를 구분한다. 이미 해낸 일을 다시 시키지 않는다.
- 성공한 획득이나 작동 뒤에만 완료를 기록한다. 가방이 가득 차 획득에 실패했다면 목표와 배치물을 그대로 둔다.
- 반복 상호작용, 재대화, 저장 후 불러오기로 물건·보상을 중복 지급하거나 진행을 되돌리지 않는다.
- 실제 잠금, 전원, 이동 경로 같은 물리적 선행 조건은 유지한다. 의뢰를 아직 듣지 않았다는 사유만으로 가능한 행동을 막지 않는다.
- 주요 사건과 전투를 자동으로 모두 건너뛰지 않는다. 미리 충족한 목표 단계만 생략하고 필요한 대화·사건은 이어서 진행한다.

1스테이지는 `Solved`에 목표별 완료 사실을 저장한다. `CompleteObjective`로 성공을 기록하고, `HasCompletedObjective`로 확인하며, `ResolveObjectivePhase`로 새 단계 진입과 복원 시 선행 달성을 반영한다. 기존 저장의 도구·조명 완료 단계도 호환한다.

현재 적용 예시는 나무 판·고무 망치 선행 획득 후 6호차 상인 대화, 조명 선행 작동 후 2호차 상인 대화다. 앞으로 목표를 추가할 때도 두 순서(의뢰→수행, 수행→의뢰), 중복 실행, 실패 후 재시도, 저장·불러오기를 함께 확인한다.
